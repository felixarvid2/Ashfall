## What's new since v1.3.0

Ashfall on the AYN Thor: an Android build for the dual-screen handheld.

### AYN Thor
- Install `ashfall-v1.3.1-thor.apk` on the Thor (allow installs from unknown sources). Later versions install
  over it and keep your saves.
- The game runs on the top screen, played with the built-in controller; the Back button works like Escape.
- The bottom screen shows life, resource, level, zone, gold and potions, with buttons for the inventory,
  character, skills, quests, map, potion, flare, mount and pause.
- The controller rumbles on big hits and level-ups (Settings > Vibration).
- First Thor build: the bottom-screen panel, controller routing and performance have not been tested on a device
  yet. If the game stutters, lower the graphics preset in Settings.

The web build is unchanged. Saves from v1.3.0 load unchanged.
